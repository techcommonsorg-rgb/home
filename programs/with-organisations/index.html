Program development

Build the format around the setting.

TechCommons can discuss coding programs, workshops and project days shaped around a school community.

For schools

Additional coding opportunities shaped with each school.

School programs are intended for settings seeking extra technology learning, including communities where students face barriers to extracurricular digital education. Program structure is discussed with each school.

Beginner Python course

A structured multi-session introduction built around clear concepts and project work.

Introductory workshop

A focused session that introduces coding through a manageable practical task.

Technology or career talk

An age-appropriate discussion linked to real technical learning and pathways.

Hackathon or project day

A defined build brief, working period and presentation format for a student cohort.

What shapes the proposal

Discussion considers student demand, device and internet availability, location, school supervision capacity, timetable compatibility and TechCommons instructor capacity.

What a school may coordinate

  • A suitable room, devices and internet
  • Student communication and coordination
  • A school staff supervisor
  • Accessibility information
  • Agreed operating resources
